# Changelog

## v1.0.0
- Initial cross-platform release of **PingMap** for **Linux (AppImage, DEB, RPM, tar.gz)**, **Windows 11 (MSI, Portable ZIP)**, and **Android (APK)**.
- Multi-game server presets: **CS2 / FACEIT**, **Valorant**, **League of Legends**, **Fortnite / Apex**, **DNS / Core**, plus persistent **Custom** IP/host targets.
- Real-time TCP RTT latency, min/avg/max, jitter, packet loss %, live sparklines, detailed latency chart, best-server recommendation banner, and 5× burst test.
